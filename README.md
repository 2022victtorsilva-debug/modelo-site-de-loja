# Modelo Site de Loja — Vitta Moda

Modelo de site/vitrine para loja de moda feminina.

## Tecnologias

- React 19
- TanStack Start / TanStack Router
- TypeScript
- Tailwind CSS 4
- Vite

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

O projeto é independente do Lovable e pode ser hospedado em uma plataforma compatível com aplicações Vite/TanStack Start.
